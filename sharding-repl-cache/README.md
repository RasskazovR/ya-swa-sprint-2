# Yandex SWA Sprint 2 - Задание 4 - Кэширование

## Как запустить

Перейти в директорию с приложением

```shell
cd ya-swa-sprint-2/sharding-repl-cache
```

Запускаем mongodb, redis и приложение

```shell
docker compose up -d
```

Инициализируем конфигурационный сервер, шарды с репликами, роутер и заполняем БД

```shell
bash ./scripts/mongo-init.sh
```

### Рекомендованная среда для запуска
Тестировалось на Ubuntu 22.04

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080
